# 🧮 BMI Calculator (Tkinter GUI)

A simple and interactive **BMI (Body Mass Index) Calculator** built using **Python Tkinter** and **Pillow (PIL)**.  
It allows users to input or slide their **height** and **weight** to calculate their BMI instantly, along with a visual and textual health assessment.

---

## 🧰 Tech Stack

- **Python 3**
- **Tkinter** — For GUI components  
- **Pillow (PIL)** — For handling and resizing images dynamically  
- **ttk** — For styled sliders  

---

## ⚙️ Features

- 📏 **Interactive Sliders** for selecting height (cm) and weight (kg)  
- 🧠 **Instant BMI Calculation** and classification  
- 💬 **Health Suggestion Messages** based on BMI category  
- 🧍 **Dynamic Character Visualization** that changes with height input  
- 🎨 **Attractive and modern interface** built using Tkinter  

---

## 🚀 How to Run

### 1. Clone the Repository
```bash
git clone https://github.com/SNEH-17PATEL/BMI-Calculator.git
cd BMI-Calculator
```

### 2. Install Dependencies
```bash
pip install pillow
```

### 3. Run the Application
```bash
python BMI_Calculator.py
```
